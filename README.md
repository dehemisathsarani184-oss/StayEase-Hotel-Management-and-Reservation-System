# StayEase – Hotel Management System 🏨

StayEase is a web-based hotel management system designed to simplify hotel operations through a user-friendly interface and a centralized database. The system helps manage rooms, room types, reservations, guests, payments, and invoices efficiently.

## 🚀 Features

- **Room Management** – Add, view, update, and delete room details.
- **Room Type Management** – Manage room categories, capacity, descriptions, and pricing.
- **Reservation Management** – Manage hotel booking records.
- **Guest Management** – Maintain guest information.
- **Payment Management** – Manage payment records.
- **Invoice Management** – Organize invoice information.
- **Database Integration** – Store and retrieve application data using MySQL.
- **Admin Interface** – Manage hotel operations through a web-based dashboard.

- Node.js and npm

## 🗄️ Database

StayEase uses MySQL to store and manage hotel-related information. The database includes tables for rooms, room types, guests, reservations, payments, invoices, and users, depending on the configured schema.

## 🎯 Project Objective

The main objective of StayEase is to provide a centralized solution for managing essential hotel operations, reducing manual work, and improving the organization of hotel information.

## 👩‍💻 Developer

Developed as a portfolio project to practice full-stack web development, REST API integration, database management, and CRUD operations.
